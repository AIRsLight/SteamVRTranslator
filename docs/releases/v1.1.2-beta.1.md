本测试版基于 dev 分支覆盖更新，保留 v1.1.2-beta.1 的版本号和下载地址。

### 字幕与模型生命周期

- 修复字幕监听启动、停止、重新连接和退出时的生命周期问题，改善 Windows 进程音频捕获及无声时的音频段提交。
- 语音输入、字幕与文件重放可复用同配置的 SenseVoice 常驻进程；取消某个客户端不会误杀其他客户端正在使用的模型。
- 语音输入请求优先于等待中的字幕请求；取消后的旧识别结果不会被分配给下一次请求。
- Pyannote 分段与 ERes2Net 声纹模型改为字幕专用常驻复用，普通语音输入不加载它们。
- 增加加载失败、快速启停、异常恢复、模型复用和资源释放的回归验证与诊断说明。

### 语音提示音

- 支持开始、持续和结束提示音，经已安装的 VB-CABLE 虚拟麦克风发送至游戏。
- 提供 VB-CABLE 下载、安装和卸载入口，并改进设备识别及不可用状态提示。
- 支持本地回响、测试预听和自定义音效；内置开始/结束音改为清脆提示音，持续音降低高频刺激。

### 其他

- 保留 Android 镜像长宽比、Windows 显示缩放与触摸映射修复，以及叠加层动作集和隐藏后恢复交互修复。
- 收录 SenseVoice、Nemotron 和 Moonshine 的同机对照结果与复跑工具；应用继续使用现有 ASR 后端，本版没有新增 Nemotron 或 Moonshine 模型入口。
- 修复同名测试版覆盖发布流程，更新压缩包和 SHA-256 校验文件。

下载 `SteamVRTranslator-win-x64.zip`，解压使用。该包为 Windows x64 的 .NET 8 非自包含版本，ASR 模型和 VB-CABLE 仍通过程序内入口单独下载。
